> **"생각은 맥 메모장처럼 가볍게 끄적이고, 정리는 AI 지식 뇌가 알아서 싹!"**

## 🚀 1. 빠른 시작 및 다운로드 (Download & Install)

![공식 랜딩 페이지 & 다운로드 허브](./images/guide_1_landing.png)

MemoPod는 무거운 전자(Electron) 프레임워크 대신 순수 네이티브 경량 엔진으로 제작되어 **압도적인 0.2MB 용량과 0.1초의 번개 같은 실행 속도**를 자랑합니다.

### 🌐 공식 접속 링크
- **공식 랜딩 페이지**: [https://setupod.com/memopod](https://setupod.com/memopod)
- **3단 퀵노트 메인 앱**: [https://setupod.com/memopod/quick](https://setupod.com/memopod/quick)
- **3D 스티커 메모 위젯**: [https://setupod.com/memopod/sticky](https://setupod.com/memopod/sticky)
- **AI 웹 지휘소 대시보드**: [https://setupod.com/memopod/app](https://setupod.com/memopod/app)

---

### 🍏 Mac 사용자 설치 방법
1. **다운로드**: [https://setupod.com/assets/MemoPod_2.0_Installer.dmg](https://setupod.com/assets/MemoPod_2.0_Installer.dmg) (단 **0.26MB**)
2. 다운로드받은 `MemoPod_2.0_Installer.dmg`를 더블 클릭하여 마운트합니다.
3. `MemoPod.app` 아이콘을 오른쪽 `Applications(응용 프로그램)` 폴더로 드래그합니다.
4. **최초 실행 시**:
   - `확인할 수 없는 개발자` 팝업이 뜰 경우, 앱 아이콘을 **우클릭(또는 Control + 클릭) 후 [열기]**를 누르면 1초 만에 실행되며 다음부터는 더블 클릭으로 열립니다.

### 🪟 Windows 사용자 설치 방법
1. **다운로드**: [https://setupod.com/assets/MemoPod_2.0_Windows_Portable.zip](https://setupod.com/assets/MemoPod_2.0_Windows_Portable.zip) (단 **0.07MB**)
2. 압축을 해제한 후 `MemoPod.bat`을 더블 클릭합니다.
3. 크롬 또는 엣지(Edge)의 주소창과 탭이 없는 **독립 앱 창**으로 깔끔하게 즉시 구동됩니다.

### 📱 아이폰 / 아이패드 모바일 사용법
1. 모바일 Safari 또는 Chrome에서 **[https://setupod.com/memopod/quick](https://setupod.com/memopod/quick)** 접속
2. 하단 중앙의 **[공유]** 아이콘 터치 → **[홈 화면에 추가]** 선택
3. 홈 화면에 생성된 'MemoPod' 아이콘을 누르면 앱스토어 앱처럼 전체화면으로 쾌적하게 사용할 수 있습니다.

## 📝 2. 3단 퀵노트 사용법 (Apple Notes Pro Mode)

![3단 퀵노트 인터페이스](./images/guide_2_quick.png)

애플 순정 메모장의 정갈함과 전문 지식 도구의 파워를 결합한 핵심 인터페이스입니다.

1. **좌측 (폴더 트리)**:
   - `+ 새로운 폴더`를 눌러 업무, 부업, 개발, 아이디어 등 폴더를 무제한 생성하고 분류할 수 있습니다.
2. **중앙 (스마트 메모 리스트)**:
   - 검색창을 통해 수천 개의 메모를 실시간 초성/키워드로 즉시 찾아냅니다.
   - 각 메모 카드 하단에 **`To-Do n개 미완료`** 배지가 자동으로 추출되어 중요한 할 일을 놓치지 않습니다.
3. **우측 (마크다운 & To-Do 에디터)**:
   - `- [ ]` 또는 `- [x]` 문법으로 체크리스트를 손쉽게 작성할 수 있습니다.
   - 상단 툴바를 통해 글꼴 스타일, 음성 메모, 휴지통, 스티커 모드 전환을 원클릭으로 제어합니다.
4. **실시간 저장**:
   - 타이핑하는 즉시 로컬 스토리지와 브로드캐스트 채널을 통해 실시간으로 안전하게 저장됩니다.

## 🧸 3. 3D 스티커 메모 위젯 사용법 (Sticky Note)

![3D 스티커 메모 위젯](./images/guide_3_sticky.png)

화면 한 켠에 띄워두고 급한 일정이나 아이디어를 포스트잇처럼 직관적으로 관리할 수 있는 모드입니다.

1. **아날로그 포스트잇 감성**:
   - 380×500 황금비율 크기와 상단 반투명 **스카치 테이프 효과**, 부드러운 드롭섀도우로 실제 메모지를 붙여둔 느낌을 제공합니다.
2. **입체 3D 스티커 부착**:
   - 상단 팔레트에서 3D 스티커(🧸 곰인형, 🌟 별, ❤️ 하트, 📌 핀, 🚀 로켓 등)를 클릭하면 메모지에 즉시 부착됩니다.
   - 마우스 커서를 올리면 입체적인 3D 틸트(Tilt) 애니메이션이 반응합니다.
3. **컴팩트 위젯 ⛶ 토글**:
   - 상단의 `⛶` 아이콘을 누르면 언제든 데스크 위젯 모드와 넓은 전체화면 모드를 즉시 오갈 수 있습니다.

## 📊 4. AI 웹 지휘소 & To-Do 자동 브리핑 (Web Headquarters)

![AI 웹 지휘소 & 데일리 브리핑](./images/guide_4_dashboard.png)

가볍게 끄적인 수많은 메모들을 한곳에 모아 AI가 구조화하고 실행 전략으로 바꿔주는 컨트롤 타워입니다.

1. **AI 데일리 액션 브리핑 (Daily Executive Briefing)**:
   - 흩어져 있는 메모들 속에서 방치된 미완료 할 일, 중요한 마감 기한을 자동으로 집계하여 달성률(%)과 함께 브리핑합니다.
2. **0.2초 초간단 메모장**:
   - 아무 생각이나 회의 낙서, 아이디어를 툭 던지면 카테고리 태깅(#business, #api, #adsense 등)이 자동으로 매겨집니다.
3. **지식 그래프 (Knowledge Graph)**:
   - 메모 간의 연관 관계를 3차원 우주 성단 형태로 시각화하여 내 지식의 흐름을 한눈에 조망할 수 있습니다.

## ☁️ 5. 크로스 디바이스 클라우드 동기화 (Cloud Sync)

1. 상단 바의 **구름(☁️) 아이콘**을 클릭합니다.
2. **카카오 로그인** 또는 **Google 로그인**을 선택합니다.
3. 로그인 즉시 Supabase 클라우드와 연결되어 **Mac ↔ Windows ↔ iPhone ↔ iPad** 간 모든 메모와 폴더가 안전하게 실시간 양방향 동기화됩니다.
