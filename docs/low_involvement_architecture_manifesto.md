## 🏛️ 1. 플랫폼 및 생태계 코어 원칙 (Core Ecosystem Pillars)

### ① 제로-서버 & 제로-번 구조 (Zero-Burn Architecture)
- **원칙:** 모든 계산기, 이미지 가공, PDF/텍스트 생성 도구는 **100% 사용자 브라우저(클라이언트 사이드 JavaScript, Canvas, Web API)**에서 동작해야 한다.
- **이유:** 서버 비용, 백엔드 DB 비용, LLM 유료 API 호출 비용을 0원으로 유지해야 트래픽이 폭증해도 적자가 나지 않는 영구 패시브 인컴(Passive Income) 비즈니스가 성립된다.
- **예외 없는 개인정보 보호:** 사용자가 입력한 상품 원가, 매출액, 고객 정보, 이미지는 절대 외부 서버로 전송하지 않는다. (100% 로컬 프라이버시 원칙)

## 🎨 2. UX & 인터랙션 디자인 불변 원칙 (UI/UX Standards)

### ① 첫 화면 즉시 실행 (Zero-Friction Above-The-Fold)
- **금지:** 거창한 인트로 배너, 긴 텍스트 설명, 회원가입 유도 버튼으로 화면 상단을 채우는 행위.
- **의무:** 첫 페이지에 진입하자마자 **상단 1초 안에 메인 계산기/입력 폼**이 나타나야 한다. 사용자가 스크롤을 내리지 않고도 즉시 값을 입력하고 결과를 확인할 수 있어야 이탈률이 최소화된다.

### ② 상단 퀵 도구 탭 바 (Top Tool Pills Bar) 의무화 (BrewOak Pattern)
- **구조:** GNB 네비게이션 바로 아래에 전체 도구로 즉시 이동할 수 있는 **가로 고정(Sticky) 탭 바**를 둔다.
  - 마진 계산기 | 애드센스 진단 | 이미지 가공 | 견적서 생성 | 3.3% 실수령액 | 태그 조합기
- **효과:** 사용자가 사이트 하단까지 스크롤하지 않아도 다른 도구들이 존재함을 1초 만에 인지하고 페이지뷰(PV)와 체류 시간을 극대화한다.

## 🛡️ 3. 구글 애드센스 승인 및 SEO 품질 원칙 (AdSense & SEO Defense)

### ① Thin Content(가치 없는 인벤토리) 철통 방어
- 단순 계산기 폼만 두면 구글 애드센스 심사 봇이 *"가치 없는 인벤토리(콘텐츠 없음)"*로 100% 거절한다.
- **의무 조치:** 모든 도구 화면 하단에는 반드시 **1,500자 이상의 실무 심층 가이드(Helpful Content)**를 결합한다:
  - 플랫폼별 실질 수수료 비교 분석 표
  - 공식 계산 산식 및 역마진 방어 전략
  - 초보자를 위한 단계별 체크리스트
  - 구글 검색용 FAQ Schema (`FAQPage`) 구조화 데이터

### ② 절대적 진실성 (No Fabricated Credentials)
- 전문성을 증명하겠다고 가짜 의사, CFA, 대기업 출신 등의 페르소나를 임의로 조작하지 않는다.
- 데이터와 공공 수수료 고시, 국세청 세법, 플랫폼 공식 정책에 기반한 객관적인 근거를 제시한다.

### ③ 필수 법적 4대 페이지 상시 구축
- 모든 프로젝트는 도구 페이지만 만들지 않고 아래 4개 페이지를 필수 배포한다:
  1. `about.html` (운영 주체, 철학, 패밀리 생태계)
  2. `contact.html` (고객센터, 문의 안내, 사업자 정보)
  3. `privacy.html` (쿠키 및 구글 애드센스 제3자 광고 사업자 고지 포함 개인정보처리방침)
  4. `terms.html` (이용약관 및 면책 조항)

## 📋 4. 신규 마이크로 도구 추가 시 체크리스트 (Step-by-Step SOP)

신규 도구(예: 7번 SEO 점검기, 8번 PDF 통합 도구 등)를 제작할 때는 반드시 다음 단계를 순서대로 밟는다:

- [ ] **Step 1:** 브라우저 순수 로컬 기술로 구현 가능한지 검토 (서버 비용 0원 유지)
- [ ] **Step 2:** `tools/{tool-name}.html` 단독 파일 생성 (Web & Mobile 반응형)
- [ ] **Step 3:** 상단 GNB + **Top Tool Pills Bar**에 활성 링크 배치
- [ ] **Step 4:** 도구 폼 하단에 **SEO 실전 가이드 & FAQ Schema** 작성
- [ ] **Step 5:** `index.html`의 카탈로그 섹션에 해당 도구 카드를 `LIVE` 배지로 전환
- [ ] **Step 6:** `sitemap.xml`에 신규 도구 URL 우선순위(0.9) 등록
- [ ] **Step 7:** `setupod/docs/low_involvement_web_business_top20.md` 진행 상황 트래커 갱신
