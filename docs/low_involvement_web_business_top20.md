## 🌐 1. 브랜드 및 플랫폼 3대 축 (Pillars)

`autosite.kr`은 개별 도구 사이트들을 분산시키는 대신, 단일 우산 브랜드(Umbrella Brand) 아래에서 도메인 권위(Domain Authority)와 인프라를 공유하는 **마이크로 유틸리티 허브**로 구축합니다.

```text
autosite.kr (AutoSite Tools)
│
├── / (홈/메인 허브)
│     └── 전체 도구 디렉토리, 인기 도구 랭킹, 플랫폼 소개
│
├── 🛠️ Auto Tools (/tools/...)
│     ├── /tools/margin-calculator  (1위. 온라인 판매자 순이익 계산기)
│     ├── /tools/adsense-checker    (2위. 애드센스 승인 준비도 진단기)
│     ├── /tools/image-batch        (3위. 쇼핑몰 이미지 가공기)
│     └── ... (TOP 20 도구 순차 탑재)
│
├── 🚀 Auto Build (/build/...)
│     ├── 표준화된 마이크로 도구 빌드 템플릿 (신규 도구를 몇 시간 만에 출시)
│     └── 타 블로그/웹사이트용 "임베드(Embed) 위젯 코드" 생성 (강력한 백링크 유입 효과)
│
└── 💰 Auto Revenue (/account & /pricing)
      ├── 공통 결제/크레딧/구독 모듈 (도구별 중복 개발 방지)
      ├── 애드센스 최적화 슬롯 및 광고 제거 Pro 멤버십
      └── 오픈마켓/금융/호스팅 제휴 링크 연동
```

### 🛡️ AI 및 검색엔진 '자동차(Automotive)' 오인 방지 프로토콜
* **문제점**: 'Auto' 단어 특성상 LLM 및 검색엔진이 '자동차/정비' 분야로 오인할 가능성 존재.
* **해결책**:
  1. **네이밍 고정**: 단독 'AutoSite' 대신 **'AutoSite Tools'** 또는 **'오토사이트 툴스'**로 웹 도구 카테고리를 명시.
  2. **헤더 카피라이팅**: *"웹 비즈니스를 위한 올인원 마이크로 툴킷 | One-click Web Utilities & Calculators"*
  3. **구조화 데이터(Schema.org)**: HTML 헤더에 `WebApplication` 및 `BusinessApplication` 필수 명시.

## 🎯 3. 단계별 실행 로드맵 (Action Roadmap)

### Phase 1 — MVP 출시 및 트래픽 검증 (1순위 집중)
- **타깃 도구**: `autosite.kr/tools/margin-calculator` (온라인 판매자 순이익 계산기)
- **핵심 목표**: AI API 비용 없이 순수 클라이언트 로직으로 가동, 0원 운영 체계 확립.
- **주요 기능**:
  - 네이버 스마트스토어, 쿠팡(윙/로켓그로스), 11번가 등 오픈마켓별 최신 수수료 프리셋.
  - 마진율, 순이익, 손익분기 ROAS(광고비 회수 기준) 1초 자동 산출.
  - **콘텐츠 결합(Helpful Content)**: 계산기 하단에 *"2026 플랫폼별 실질 수수료 비교 분석"*, *"ROAS 함정과 마진 방어 전략"* 배치로 SEO 및 애드센스 고품질 평가 확보.
- **수익화 테스트**: 결과 엑셀/PDF 내보내기, 상품별 마진 로컬 저장, 셀러 제휴 배너.

### Phase 2 — 데이터/진단형 도구 연계 (2순위)
- **타깃 도구**: `autosite.kr/tools/adsense-checker` (애드센스 승인 준비도 진단기)
- **핵심 목표**: 기존 블로그/콘텐츠 운영 경험을 점수화 알고리즘으로 상품화.
- **차별화**: 1회 정밀 진단 보고서, 개선 체크리스트, 주간/월간 상태 모니터링 구독.

### Phase 3 — Auto Build & 도구 허브 확장
- 검증된 성과를 바탕으로 3위(이미지 일괄 가공), 4위(견적서 생성기) 순차 런칭.
- 타 사이트에 계산기를 심을 수 있는 **"임베드 위젯(Embed Widget)"** 기능 배포 → 외부 백링크 자동 확장.

## ⚠️ 5. 불변의 운영 원칙

1. **One-by-One 원칙**: 20개를 한 번에 만들지 않고, 1개씩 시장 검증(PMF) 후 확장한다.
2. **Zero-Burn 구조 우선**: 초기 단계에서는 AI API 호출 비용이 들지 않는 도구를 우선 배치해 유지비를 0원에 가깝게 통제한다.
3. **Thin Content 방지**: 도구 입력 폼만 두지 않고, 실질적인 해결 가이드와 통계 데이터를 함께 제공해 구글 검색엔진 최적화(E-E-A-T)를 달성한다.
4. **절대 투명성**: 애드센스 100% 승인이나 무조건적인 매출 증대 등 허위·과장 문구를 절대 사용하지 않는다.
