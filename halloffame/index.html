FLAGSHIP #01 독립 법인 사업화

툼카드 (TOOMCARD)

종이 명함의 시대를 끝내는 실시간 3D 인터랙티브 스마트 명함. 2.4MB 무거운 GIF 대신 2KB 초경량 3D 메탈 엠블럼과 NFC 칩셋을 결합한 차세대 모바일 프로필 플랫폼.

조합된 셋업팟 레고 블록
145호 3D 목업/엠블럼 + 올인원 멀티링크 엔진 + NFC 다이내믹 라우터
✓ toomcard.com 정식 런칭 사이트 보기
FLAGSHIP #02 3D 공간 커머스

THE DESKTERIOR 3D

개발자 & 크리에이터 감성 데스크셋업 3D 룸투어 쇼룸. 스크린바 조명 스위치, 기계식 키보드 타건음, 모션데스크 승강을 직접 만져보며 실제 장비 견적을 확인하는 3D 공간.

조합된 셋업팟 레고 블록
147호 오토파일럿 데스크 + Three.js 3D 공간 룸투어 + 장비 핫스팟 큐레이션
✓ 60FPS 브라우저 WebGL 쇼룸 데스크 투어
FLAGSHIP #03 지식창업 자동화

크몽 1초 전자책 인쇄소

글재주 없는 1인 창업가를 위해 주제 하나로 [표지 + 7개 실무 챕터 + 체크리스트 10선 + 크몽 필수 라이선스]를 A4 8페이지 완제품 PDF로 인쇄하고 3D 양장본 표지까지 세트로 뽑아내는 자동화 팩토리.

조합된 셋업팟 레고 블록
146호 AI 리드마그넷 인쇄소 + 145호 3D 양장본 썸네일 + A4 벡터 조판 엔진
✓ 오늘 밤 크몽 런칭 파이프라인 인쇄소 가동
FLAGSHIP #04 SNS 마케팅 오토메이션

도메인 플립 인스타 (Agent Forge)

도메인 플리핑과 디지털 자산 투자자를 위한 인스타그램 카드뉴스 7장 자동 생성기. Gemini 2.0이 타깃 페르소나별 카피를 작성하고 HTML Canvas로 7장 완성본을 즉시 다운로드.

조합된 셋업팟 레고 블록
셋업팟 마케팅 에이전트 + Canvas 7슬라이드 렌더러 + 페르소나 카피라이터
✓ 일일 카드뉴스 0초 제작 카드뉴스 만들기
